# Wave 1a-cli: `ss --json`, `ss --describe`, and the contract — Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox
> (`- [ ]`) syntax for tracking.

**Goal:** Every `ss` command speaks the JSON contract when asked, `ss --describe` prints the
command catalogue the desktop application renders forms from, and both halves of the contract are
written down as JSON Schema that the Python tests validate recorded streams against.

**Architecture:** `ss`'s console module becomes a `LazyConsole` whose `machine` flag a Typer
callback sets from a global `--json` option before any command body runs. Every place that today
prints a Rich `Table`, calls `input()`, or uses `typer.echo` goes through the four semantic calls
wave 1a-core added to `Console`; every command ends by emitting one `result` event through one
helper. The catalogue is a serialisation of the Typer application's own command objects, produced
by one module that knows nothing about any command. Schemas live in `sushihub/contract/`; a test
runs each read-only command in-process under `--json` in a throwaway workspace and validates every
line.

**Tech Stack:** Python 3.10+, Typer (Click underneath), Rich, pytest, `jsonschema` (test extra).

**Spec:** `docs/agent/specs/2026-09-05-hub-design.md` §7.

## The catalogue shape

```json
{
  "program": "ss",
  "version": "1.0.0",
  "contract": "1",
  "commands": [
    {
      "name": "add",
      "help": "Clone one or more stack modules into the workspace.",
      "params": [
        {"name": "modules", "kind": "argument", "type": "string", "multiple": true, "required": true,
         "default": null, "choices": null, "flags": [], "help": "Modules to clone: ..."},
        {"name": "dry_run", "kind": "option", "type": "boolean", "multiple": false, "required": false,
         "default": false, "choices": null, "flags": ["--dry-run"], "help": "Show, don't clone or install."}
      ],
      "applies_to": ["cloned", "linked", "binary"]
    }
  ]
}
```

`type` is one of `string`, `boolean`, `integer`, `number`, `path`, `choice`. `applies_to` is the
constant list of all three presence forms for every command in this wave; wave 2 narrows it.
`version` is read from the installed distribution (`importlib.metadata.version("sushistack-cli")`),
falling back to `"0"` when not installed.

```python
"""The schemas are the contract; a stream that violates them is a defect."""

import json
from pathlib import Path

import jsonschema
import pytest

CONTRACT = Path(__file__).resolve().parents[2] / "sushihub" / "contract"


def _schema(name):
    return json.loads((CONTRACT / name).read_text(encoding="utf-8"))


def test_events_schema_accepts_each_kind():
    v = jsonschema.Draft202012Validator(_schema("events.schema.json"))
    for ev in [
        {"event": "line", "level": "info", "message": "m"},
        {"event": "command", "command": "c"},
        {"event": "header", "title": "t"},
        {"event": "panel", "title": "t", "body": "b"},
        {"event": "table", "title": "", "columns": ["a"], "rows": [["1"]]},
        {"event": "progress", "label": "l", "index": 1, "count": 2, "fraction": None},
        {"event": "result", "ok": True, "payload": {}},
        {"event": "prompt", "id": "prompt-1", "message": "m", "default": None},
    ]:
        v.validate(ev)


def test_events_schema_rejects_an_unknown_key_and_level():
    v = jsonschema.Draft202012Validator(_schema("events.schema.json"))
    with pytest.raises(jsonschema.ValidationError):
        v.validate({"event": "line", "level": "debug", "message": "m"})
    with pytest.raises(jsonschema.ValidationError):
        v.validate({"event": "header", "title": "t", "extra": 1})


def test_describe_schema_accepts_the_documented_example():
    v = jsonschema.Draft202012Validator(_schema("describe.schema.json"))
    v.validate({"program": "ss", "version": "1.0.0", "contract": "1", "commands": [
        {"name": "add", "help": "h", "applies_to": ["cloned", "linked", "binary"], "params": [
            {"name": "modules", "kind": "argument", "type": "string", "multiple": True, "required": True,
             "default": None, "choices": None, "flags": [], "help": "x"}]}]})
```

### Task 3: The catalogue

**Files:**
- Create: `cli/sushistack/describe.py`
- Test: `cli/tests/test_describe.py`

**Interfaces:**
- Produces:
  ```python
  CONTRACT_VERSION = "1"
  ALL_PRESENCE = ("cloned", "linked", "binary")
  def catalogue(app: typer.Typer) -> dict
  ```
  Implementation: `click_app = typer.main.get_command(app)`; iterate
  `click_app.commands.items()` sorted by name; for each `click.Command` read `help` (first
  paragraph of `cmd.help`, Rich markup stripped with `rich.markup.escape`'s inverse: strip
  `[...]` tags via `rich.text.Text.from_markup(s).plain`), and for each `param` in `cmd.params`:
  `kind` from `isinstance(param, click.Argument)`; `type` from `param.type`: `click.BOOL` →
  boolean, `click.INT` → integer, `click.FLOAT` → number, `click.Path` → path, `click.Choice` →
  choice with `choices=list(param.type.choices)`, else string; `multiple` from
  `param.multiple or param.nargs == -1`; `required` from `param.required`; `default` from
  `param.default` (None when `...`/unset; booleans as booleans); `flags` from `param.opts` for
  options, `[]` for arguments; `help` from `getattr(param, "help", "") or ""`. Skip the
  `--help` option and the callback's own options.

### Task 4: The callback, `_finish`, and `home`

**Files:**
- Modify: `cli/sushistack/cli.py`
- Test: `cli/tests/test_json_streams.py` (add)

**Interfaces:**
- Produces, in `cli.py`:
  ```python
  @app.callback(invoke_without_command=True)
  def _root(ctx: typer.Context,
            json_output: bool = typer.Option(False, "--json", help="One JSON event per line on stdout; nothing else there.", is_eager=True),
            describe: bool = typer.Option(False, "--describe", help="Print the command catalogue as JSON and exit.", is_eager=True)) -> None
  def _finish(rc: int, payload: dict | None = None) -> None
      """Emit the result event and exit with rc."""
  ```
  `_root` calls `console.set_machine(json_output)` first. With `describe`, it prints
  `json.dumps(catalogue(app), ensure_ascii=False)` followed by a newline to stdout and exits 0,
  regardless of `--json`. With no subcommand and no `--describe`, it prints help and exits 0
  (replace `no_args_is_help=True`, which does not combine with a callback).
  Every command body's `raise typer.Exit(rc)` becomes `_finish(rc)`; `status` passes its payload
  (Task 5). `home` prints through `console.info` and passes
  `{"workspace": ..., "dependencies": ...}` as payload.
  `status`'s own `--json` option stays for compatibility and is treated as the global flag: its
  body calls `console.set_machine(True)` when set, before printing.

```python
from sushistack.cli import app


def _run(args, cwd):
    import os
    env = {**os.environ, "SUSHISTACK_HOME": str(cwd)}

def _events(result):
    return [json.loads(l) for l in result.stdout.splitlines() if l.strip()]


@pytest.fixture

    (tmp_path / "cli" / "config.toml").write_text('[cli]\ntheme = "default"\n', encoding="utf-8")

def test_describe_prints_a_valid_catalogue(workspace):
```
