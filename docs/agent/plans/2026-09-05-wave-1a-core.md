# Wave 1a-core: events and the JSON renderer in sushicore — Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox
> (`- [ ]`) syntax for tracking.

**Goal:** Give every Sushi CLI a machine-readable output mode by adding a third `Renderer` to
`sushicore` that writes one JSON event per line, and the three semantic calls (`table`,
`progress`, `prompt`) the desktop application needs and the CLIs today do by hand through Rich.

**Architecture:** The `Renderer` protocol grows from four methods to eight. `RichRenderer` and
`PlainRenderer` implement the new four in their own idiom; `JsonRenderer` implements all eight as
events on stdout and sends every stray Rich print to stderr so stdout stays parseable. `Console`
gains `table`, `progress`, `result` and `prompt`, which only translate to renderer calls, as its
existing methods do. `build_console` and `LazyConsole` learn one flag, `machine`, that selects the
JSON renderer. No consumer changes in this wave; wave 1a-cli wires `ss`.

**Tech Stack:** Python 3.10+, Rich, pytest. No new dependency.

**Spec:** `docs/agent/specs/2026-09-05-hub-design.md` §4 and §7.

## The contract this wave fixes

One JSON object per line, UTF-8, no other bytes on stdout. Keys are stable; the desktop
application and wave 1a-cli's schema depend on them.

```json
{"event": "line",     "level": "info",   "message": "..."}          level ∈ info|success|warn|error
{"event": "command",  "command": "cmake -S . -B build"}
{"event": "header",   "title": "SushiStack Install"}
{"event": "panel",    "title": "...", "body": "..."}
{"event": "table",    "title": "...", "columns": ["A","B"], "rows": [["a1","b1"]]}
{"event": "progress", "label": "install-deps", "index": 2, "count": 4, "fraction": 0.5}   fraction may be null
{"event": "result",   "ok": true, "payload": {}}
{"event": "prompt",   "id": "confirm-1", "message": "...", "default": "n"}               default may be null
```

A `prompt` event is answered by one line on stdin. The renderer reads it and returns it stripped;
an empty line returns the default; EOF returns the default.

  ```python
  def event_line(kind: str, **fields) -> str
  ```

### Task 2: The renderer protocol grows, and the two existing renderers follow

**Files:**
- Modify: `sushicore/sushicore/renderer.py`
- Test: `sushicore/tests/test_console_semantics.py` (renderer half; the Console half is Task 3)

**Interfaces:**
- Produces, on `Renderer`, `RichRenderer`, `PlainRenderer`:
  ```python
  def table(self, title: str, columns: list[str], rows: list[list[str]], header_style: str) -> None
  def progress(self, label: str, index: int, count: int, fraction: float | None) -> None
  def result(self, ok: bool, payload: dict) -> None
  def prompt(self, prompt_id: str, message: str, default: str | None) -> str
  ```
- `RichRenderer.table` builds a `rich.table.Table(title=title, header_style=header_style)` and
  prints it. `RichRenderer.progress` prints `f"[{label}] {index}/{count}"` plus a percentage when
  `fraction` is not None. `RichRenderer.result` prints nothing (the human already saw the lines).
  `RichRenderer.prompt` uses `rich.prompt.Prompt.ask(message, default=default, console=self._console)`
  and returns the string; on EOF returns `default or ""`.
- `PlainRenderer` does the same in plain text: table as `title`, a header row, rows joined with two
  spaces; prompt through `input()`, same EOF rule.

- [ ] **Step 1: Write the failing tests** (renderer half)

```python
"""Each renderer speaks the four new calls in its own idiom."""

import io

from sushicore.renderer import PlainRenderer, RichRenderer
from sushicore.theme import Theme


def test_plain_table_prints_title_header_and_rows():
    out = io.StringIO()
    r = PlainRenderer(stream=out)
    r.table("Modules", ["Module", "State"], [["sushiruntime", "cloned"]], header_style="bold")
    text = out.getvalue()
    assert "Modules" in text and "Module" in text and "sushiruntime" in text and "cloned" in text


def test_plain_progress_prints_index_of_count():
    out = io.StringIO()
    PlainRenderer(stream=out).progress("install-deps", 2, 4, 0.5)
    assert "install-deps" in out.getvalue() and "2/4" in out.getvalue()


def test_plain_result_prints_nothing():
    out = io.StringIO()
    PlainRenderer(stream=out).result(True, {"x": 1})
    assert out.getvalue() == ""


def test_plain_prompt_returns_default_on_empty_line(monkeypatch):
    monkeypatch.setattr("builtins.input", lambda *_a, **_k: "")
    assert PlainRenderer(stream=io.StringIO()).prompt("p1", "Continue?", "n") == "n"


def test_plain_prompt_returns_default_on_eof(monkeypatch):
    def _eof(*_a, **_k):
        raise EOFError
    monkeypatch.setattr("builtins.input", _eof)
    assert PlainRenderer(stream=io.StringIO()).prompt("p1", "Continue?", "n") == "n"


def test_rich_table_renders_rows(capsys):
    r = RichRenderer(Theme(), no_color=True)
    r.table("Modules", ["Module", "State"], [["sushiruntime", "cloned"]], header_style="bold")
    captured = capsys.readouterr().out
    assert "sushiruntime" in captured and "cloned" in captured
```

### Task 4: `JsonRenderer`

**Files:**
- Modify: `sushicore/sushicore/renderer.py`
- Test: `sushicore/tests/test_json_renderer.py`

**Interfaces:**
- Produces:
  ```python
  class JsonRenderer:
      def __init__(self, stream=None, error_stream=None, input_stream=None) -> None
          # stream defaults to sys.stdout, error_stream to sys.stderr, input_stream to sys.stdin
      raw -> rich.console.Console(no_color=True, file=self._error_stream)
      # all eight methods write event_line(...) + "\n" to stream and flush
      # prompt writes the event, reads one line from input_stream; "" or EOF -> default or ""
  ```
- Consumes: `sushicore.events.event_line`.

- [ ] **Step 1: Write the failing tests**

```python
"""One event per call, on stdout alone."""

import io
import json

from sushicore.renderer import JsonRenderer


def _renderer(stdin_text=""):
    out, err = io.StringIO(), io.StringIO()
    r = JsonRenderer(stream=out, error_stream=err, input_stream=io.StringIO(stdin_text))
    return r, out, err


def _events(out):
    return [json.loads(l) for l in out.getvalue().splitlines()]


def test_line_event_carries_level_and_message():
    r, out, _ = _renderer()
    r.line("bold blue", "[INFO]", "hello")
    assert _events(out) == [{"event": "line", "level": "info", "message": "hello"}]


def test_level_is_derived_from_the_prefix_not_the_style():
    r, out, _ = _renderer()
    r.line("bold red", "[WARN]", "x")
    assert _events(out)[0]["level"] == "warn"


def test_each_call_is_exactly_one_line():
    r, out, _ = _renderer()
    r.header("H"); r.command("c", "i", "[INFO]", "cmake"); r.panel("t", "a\nb", "red")
    r.table("T", ["A"], [["1"]], "bold"); r.progress("s", 1, 2, None); r.result(True, {})
    assert len(out.getvalue().splitlines()) == 6
    assert [e["event"] for e in _events(out)] == ["header", "command", "panel", "table", "progress", "result"]


def test_raw_writes_to_the_error_stream_not_stdout():
    r, out, err = _renderer()
    r.raw.print("stray")
    assert out.getvalue() == "" and "stray" in err.getvalue()


def test_prompt_emits_the_event_and_reads_one_line():
    r, out, _ = _renderer("yes\n")
    assert r.prompt("prompt-1", "Go?", "n") == "yes"
    assert _events(out) == [{"event": "prompt", "id": "prompt-1", "message": "Go?", "default": "n"}]


def test_prompt_returns_default_on_eof():
    r, _, _ = _renderer("")
    assert r.prompt("prompt-1", "Go?", "n") == "n"
```

The level is derived from the icon prefix because that is the only signal `Console.line` passes
that names the semantic call. Rule: the first of `info`, `success`, `warn`, `error` whose name
appears, case-insensitively, in the prefix; a prefix that names none of them (an emoji set, an
empty prefix) yields `"info"`. Document this on the method.
