# KI-17 A CUDA 13 toolkit breaks a Pascal build far from the cause

The row of this entry is in `docs/backlog/TOOLCHAINS.md`. This file holds what did not fit the row.

- Origin: toolchain
- Cause: CUDA 13 removed `sm_6x`; sushicore picks 12.x for a Pascal machine, but `SUSHISYSTEMS_CUDA_RELEASE`, a `CUDA_PATH` to another toolkit or an `SR_CUDA_ARCH` naming an absent card bypasses the choice
- Recognise: `nvcc --version`, `hub doctor` and the configure pass; ptxas fails on `sm_61`
- Workaround: set `SUSHISYSTEMS_CUDA_RELEASE` to a release whose `nvcc --list-gpu-arch` lists the card
