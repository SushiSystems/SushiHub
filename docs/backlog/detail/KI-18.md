# KI-18 Changing a vcpkg port's features needs `--recurse`, which `hub install` cannot pass

The row of this entry is in `docs/backlog/TOOLCHAINS.md`. This file holds what did not fit the row.

- Origin: dependency
- Cause: vcpkg rebuilds a port with new features only with `--recurse`, and sushicore's `VcpkgManager.install` runs a plain install with no way to add it
- Recognise: after a manifest changes, say, `sdl2` to `sdl2[vulkan]`, the vcpkg step refuses and asks for `--recurse`
- Workaround: run `<dependencies>/vcpkg/vcpkg install sdl2[vulkan]:x64-windows --recurse` once, then `hub install` again; `hub home` prints the folder
